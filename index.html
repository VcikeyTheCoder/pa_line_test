    How to read the print

    Each bar is printed slow, fast, slow at the PA value shown next to it. Inspect the top layer with light from the side.

    • Left end (acceleration): push. PA too low: thin section after the speed change. PA too high: bulge after the speed change. Use the bar with even width.
    • Right end (deceleration): pull. PA too low: bulge before the speed change. PA too high: thin section before the speed change. Use the bar with even width.

    Push and pull values can come from different bars. Set them in [dual_pa] as push_pressure_advance and pull_pressure_advance. If both are the same bar, set pressure_advance in [extruder].
